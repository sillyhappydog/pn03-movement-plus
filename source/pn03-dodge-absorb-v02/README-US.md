# 北米版 GPNE08 回避吸収 v0.2

北米版 **GPNE08** 用。動作は日本版と同じ（[README.md](README.md)）: サイドステップ中は無敵、その間に受けた敵の攻撃 1 発ごとにエナジー **+100**、オーブ回収と同じ光と音。

## 日本版との違い（フックが 1 本多い）

北米版は当たり判定の仕様が違う。`BltHitEm` がやられ判定のフラグを bit0 で見るので（日本版は 0 でなければ判定する）、無敵カウンタが動いている間（フラグ 2）の弾はヴァネッサを素通りし、「当たったが無敵だった」分岐に置いた吸収フックに届かない。そこで北米版だけ `BltHitEm+0x114`（`0x8000BC40`）にフックを足し、吸収が有効・対象がプレイヤー・サイドステップ中・無敵カウンタが 0 でない、を全部満たすときだけ判定を通す。やられ判定の大きさやフラグは書き換えない。ステップ以外の無敵（被弾後など）は北米版本来の素通りのまま。

## 経過（2026-10-06）

- 夕方: ゲージ通知先の誤り（`0x801957A0` → `0x80195840`）を修正。
- 18:09: 上の判定フックを追加（Codex 実装）。ユーザーがゲーム内で吸収・ゲージ・光・音を確認（この時点は 1 発 +50）。
- 20:42: 日本版と数え方をそろえる改訂。両地域とも 1 発 1 回加算、既定 X = 100。北米版のコードの変更は既定値の 1 命令だけ（`li r0,50` → `li r0,100`）。同日ユーザーが両地域でゲーム内確認（「手触り自体は悪くなかった」）。

## 導入・確認

`GameSettings\GPNE08.ini` の `[OnFrame]` に反映済み（`Dodge Absorb v0.2`、289 行、本体 `0x80190400`〜 1140 bytes）。**改訂前のセーブステートはロードしない**（旧コードと旧設定値 X = 50 を持ち込む）。メモリーカードのセーブからの再開は可。確認の仕方: エナジーが満タンでない状態でステージ 1 のピルツの弾にサイドステップで入り、1 発 +100、ゲージの伸び、オーブ回収の光と SE を見る。

## 検証

Unicorn で 49 ケース（日本版と共通の項目 ＋ 判定フックの通す／通さないの 8 条件）。配備 INI の統合テスト（`test_ini_chain.py`）。F1／F2 のセーブステートの実 RAM 上でゲーム本物の当たり判定を再生: 判定フック無しでは 0／180 本、ありで 61／180 本・63／180 本が当たり、1 発につき吸収 1 回・+100。ステップ以外の無敵と吸収オフでは 0／180 本のまま。
