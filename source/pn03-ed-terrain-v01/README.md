# P.N.03 エナジードライブ地形素通り v0.1

日本版 **GPNJ08** 用。ロックオン対象を持つプレイヤーの弾（＝エナジードライブの弾）が、地形（壁・床・柱）に吸われて消えなくなる。ヴァネッサの向きや ED のモーション・照準は一切変えない。

- 弾の移動＋当たり判定 `0x8000B770` は、引数 r7 が非 0 のときだけ地形レイ `0x80007960` を飛ばし、その後に敵ヒット判定 `0x8000B9AC` を行う。敵ヒット判定は地形を一切見ない（敵リストを総当たりして当たり球と線分で判定するだけ）。
- フック `0x8000B7C8`（`cmpwi r7,0`）で、弾の所有者 `+0xE4` がプレイヤー（root+0x50 のオブジェクトリストの先頭）、対象 `+0x12C` が非 null、寿命枠 `+0x150` が正なら r7 を 0 にして地形レイを飛ばさず、枠を 1 減らす。
- 枠 `+0x150` は生成時に入る値をそのまま使う（ED の弾種 0xB〜0xD は 150、0xE／0xF は 120、ドライブ 2 の弾（クラス 8）は 300、ドライブ 7 のミサイル（クラス 1）は 150。呼出しは 1 フレーム 1 回なのでフレーム数）。弾のコードはこの欄を読まないので流用した。尽きたら元どおり地形に当たる。
- 通常射撃（対象を渡さない）と敵の弾（所有者が違う）は変わらない。ED でロックオンが無いときも変わらない。対象が死ぬか追尾が切れて `+0x12C` が 0 になった弾も、その時点から元どおり地形に当たる。
- 対象外: ドライブ 6／14（手のビーム。`0x80010898` が直接レイを飛ばす別経路）。ドライブ 3／11 の弾は元々壁で跳ね返る（`0x8000F8FC`）が、枠の間は跳ね返らず素通りする。
