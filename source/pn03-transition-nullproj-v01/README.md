# P.N.03 部屋遷移の射影ゼロ対策 v0.1（Transition Null Projection）

日本版 **GPNJ08** 用。Mission 9（ボス連戦）の合間など、カメラが止まった状態で部屋を描くフレームで、ゲームが**全ゼロの射影行列**を `GXSetProjection`（`0x80121344`）に渡すことがある。実機では全頂点が 1 点に潰れて何も描かれず黒いままだが（実機動画でも暗転）、Dolphin では w → 0 の頂点が NaN になって画面全体が巨大な三角形で埋まる。

このパッチは `GXSetProjection` の入口をフックし、渡された 4×4 行列の m00・m11・m22・m23 が全部 ±0 のときだけ、代わりに「x/y オフセット 10.0 の正射影（係数 0）」を書く。全頂点が NDC (10, 10)・w = 1 に落ちてクリップされるので何も描かれない＝実機と同じ黒。それ以外の行列は元の関数をそのまま通す（通常プレイの透視投影・HUD の正射影は m00 ≠ 0 なので対象外）。

- 本体 `0x8018C000`〜（132 bytes、34 行）。回避吸収 v0.2 の本体 `0x8018C800` の直下。設定ブロックは使わない。
- フック語は元命令 `0x80ADA580` のときだけ書く条件付き。関数は葉関数なので入口で LR はそのまま、ゼロ経路は `blr` で呼び出し元へ戻る。`__GXData+2` の dirty フラグは元の関数と同じく 1 にする。
- Unicorn テスト 5 ケース（ゼロ行列、−0 行列、実際の透視行列の素通り、m23 だけ非ゼロ、極小の非ゼロ）。

## 導入

Claude 側で `GameSettings\GPNJ08.ini` の `[OnFrame]` に反映済み（`Transition Null Projection v0.1` 有効）。セーブステート経由でも効く（フック語の条件が元命令なので、読み込んだ RAM に次のフレームで入る）。

## 検証

壊れた画面のセーブステート（スロット 5／6）を読み込んだ瞬間に黒くなれば成功。通常プレイ・HUD・フェードに影響がないことも確認する。
