# P.N.03 加速走りの軌跡色 v0.3

日本版 **GPNJ08** 用。加速走り（Sprint Run v0.3）の係数に応じて、ヴァネッサの両手両足の軌跡エフェクト（青）をオレンジへ混ぜる。加速走りパッチと一緒に使う（無ければ何も変えない）。

## v0.2 からの変更

**要素プールの先頭アドレスの誤り**を修正。v0.2 は `esp_sys + 0x8548` から走査していたが、そこはプールが満杯のときに返すダミー要素で、プール本体は `esp_sys + 0x8538` に入っているポインタの先（セーブステート時点で `0x80D60200`）。加速中のセーブステートで、v0.2 が動いていて t = 1.0 なのに塗った数が 0 のまま、本物のプールには ID 9・開始色 `5064FF55`・親 = プレイヤーの要素が 4 本（部位 7／12／22／18、生存 245 フレーム）青のまま生きているのを確認した。それ以外は v0.2 と同じ。

## v0.1 からの変更（v0.2）

v0.1（2026-10-01）は要素の生成時に色を書いていたが、実機では青のままだった。軌跡の要素は **ID 9**（定義の種別バイトは `+0x01`。ID 1 の「ストリップ」ではない）で、手足が動き出したときに生まれて走っている間ずっと生き続ける位置履歴型のラインなので、加速が始まる頃にはもう生成済みで、生成時のフックには二度と来ない。v0.2 は **生きている要素を毎フレーム塗る**。

## 仕組み

- フック `0x800AFE7C`（プレイヤー更新の、加速走りフックの次の命令）。加速走り本体はここへ戻ってくるので両方が連鎖する。本体は呼び出しをせず、最後に `lis r9,0x8017`（ゲームがこの先で使う値）と元命令を実行して戻る。
- `t = clamp((係数 − 1) ÷ (最大係数 − 1), 0, 1)` を加速走りのパラメータ領域（`0x8018DD80`、`SPR3`）から作る。フラグ bit1 で「最大のときだけ 1」の切替。
- t > 0 のフレーム、または前のフレームに塗っていたフレーム（t が 0 に戻った最初の 1 回）に、要素プール（`[r13 − 0x74F4]` の `+0x8538` にあるポインタの先、0x150 × `+0x8540` 件）を走査し、使用中（`+0x18` bit0、bit1 なし）・ID（`+0x19`、既定 9）・開始色バイト（`+0x88`〜、既定 `5064FF55`）・親（`+0x24` がプレイヤー、bit2）が一致する要素の RGB float（`+0x8C`／`+0x90`／`+0x94`）に `開始色 + (目標色 − 開始色) × t` を書く。α float（`+0x98`）はエンジンのフェードに任せて触らない。開始色バイトは照合キー兼復元値なので触らない。ID 9 の描画 `0x800876B8` はこの float を読み、エンジン側に RGB float を毎フレーム書き直す処理は無い。
- 待機中（t = 0 で復元済み）は走査しないので負荷なし。走査中も 1024 スロットで数千命令。

## 設定（Dolphin のメモリビューで即反映。セーブステートに含まれる）

| 絶対アドレス | 内容 | 既定 |
|---|---|---|
| `0x8018D704` | フラグ。bit0 = 有効、bit1 = 最大のときだけ切替、bit2 = 親がプレイヤーの要素だけ | 5 |
| `0x8018D708` | 目標色 `RRGGBB00`（α は使わない） | `FF880000`（オレンジ） |
| `0x8018D70C` | 対象の開始色 `RRGGBBAA`。0 なら全部 | `5064FF55` |
| `0x8018D710` | 対象のエフェクト ID。`FFFFFFFF` なら全部 | 9 |
| `0x8018D714` | 直近の t（実行時、f32） | — |
| `0x8018D718` | このフレームに塗った要素数（実行時。走行中に 4 前後になるはず） | — |
| `0x8018D720` | 塗った延べ回数（実行時、確認用） | — |

**ゲーム内未確認。** v0.1（`0x8018D000`〜）・v0.2（同じ領域）とは同時に有効にしない（INI では両方削除済み）。

## 検証

- Unicorn 2.1.4 で 29 ケース通過。合成した要素プール（プレイヤーの軌跡要素 3 本、他アクターの同色要素、空きスロットの残骸、停止中の要素、別 ID、別色）で、t = 1／0.5／0、クランプ、切替モード、親チェック OFF、ID／色の全対象、別の目標色、無効化、エフェクトシステム未初期化、プールポインタ 0、スロット 0、加速走り不在、400 フレームの加速／待機の交互（復元 1 回のあと走査なし、カウンタ整合）、r9／f13 の出口状態、非揮発レジスタ・LR・CTR 不変、ダミー要素（`esp_sys + 0x8548`、軌跡要素と同じ姿）が触られないことを確認。加速走り v0.3 本体の戻り先がこのフックであることも静的に確認。
- **Dolphin 実行は未確認。** 変わらないときは、加速中にセーブステートを 1 個作ってもらえば `source/esp_inspect.py` で要素の色と本パッチのカウンタを見て切り分けられる。
