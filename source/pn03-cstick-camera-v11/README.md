# P.N.03 C-stick独立カメラ v0.11（彼女の回転に合わせる回り込み）

日本版 **GPNJ08** 用（`GPNJ08-cstick-camera-v11.patch.txt`）と北米版 **GPNE08** 用（`GPNE08-cstick-camera-v11.patch.txt`）。v0.10（ターン中のカメラロック）に、**bit5 つきの yaw 要求を彼女の回転そのものに合わせて回る**処理を足した。移動 v0.19 と組で使う。

## 何が変わるか

- 背景（2026-10-08、ユーザー「180° ターンの追従が少し遅れている気がする」）: 180° ターンは彼女が平均 18°/コマ（最大 26.64°）で回るのに、v0.9〜v0.10 はカメラを一定 12°/コマで回していて、彼女が回り終わってから 7 コマ後に追いついていた。
- v0.11: 要求（flags bit3）に **bit5（0x20）**が添えられていると「彼女の回転に合わせる」モードで受ける。以後毎フレーム、彼女の向き（`player+0xD0`）の前フレームからの差分を測り、`step_min`（1°）以上ならその大きさを 1 コマの回転量、符号を向きにする。したがってカメラは彼女が回っただけ回る（1 コマ遅れで同じ加減速）。差分が無い間は止まって待つ。彼女が止まったあとは最後の歩幅で残りを詰め、残りが 1 歩以内でそろえる。bit3 と bit5 は受けたときに消す。
- 向きの決め方は v0.9 と同じ（残りが 170° を超えるときだけ指定の向き、他は最短側）。目標がちょうど反対のときは彼女の回転の向きに回る。目標が現在の向きそのもの（カメラ側を向いた 180° ターン）なら受けた瞬間にそろえて終わり、動かない。
- 追従要求（bit1）や bit5 なしの要求（X ロックオン）はこのモードを解除して従来どおり。C スティック入力・ゲームの視点リセット・初期化でも解除（ロック bit4 の間はスティックを無視）。
- 本体データ語: `+0x4C` 前フレームの彼女の向き、`+0x50` 合わせモードのフラグ（実行時、パッチ行は 0 のときだけ書く）。

**2026-10-08 ユーザーがゲーム内で確認「手触りとして申し分なくなった」。** 同日、この版を含む 9 本で DOL／ISO／xdelta を作り直した（ISO 版はゲーム内未確認）。
