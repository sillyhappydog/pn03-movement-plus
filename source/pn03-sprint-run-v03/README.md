# P.N.03 加速走り v0.3

日本版 **GPNJ08** 用。v0.2（2026-10-01）の実機所感「最高速に達した後、いきなりワープみたいに前方に瞬間移動するのを繰り返す」の修正版。挙動・パラメータ配置は v0.2 と同じで、第 2 フック（根の前進量の一定化）の計算だけ直した。

## 原因（v0.2）

- 第 2 フックは 1 tick の進みを層の時刻から逆算していた: `dt = +0x2A8 − +0x2AC`、ループフラグ `+0x23E == 1` なら 1 周分を足す。
- 進行関数 `0x800A1770` は毎回「`+0x2AC` ← 直前の時刻ワード、`+0x2A8` ← フレーム番号 << 6」と作り直す。ゲーム側の進行がループした tick に、本体の追加進行（端数の貸しが 1 を超えた tick）が重なると、`+0x2AC` は折返し後の時刻に上書きされる一方でフラグは 1 のまま（第 1 フックが復元する。ゲーム自身の差分計算は保存済みサンプルの差なのでこれで正しい）。第 2 フックだけが「折返し後の時刻 − 0 ＋ 1 周」＝ 17 フレームぶんと誤解し、1 周分の距離（約 3,500）を 1 tick で進めていた。1.4 倍では周回の約 4 割で発生（Unicorn の実順再現: 260 tick 中 5 回）。
- 同じ逆算のせいで、追加進行のある tick は dt が最大 0.4 フレーム短く、2〜3 tick ごとの小さなつっかえも出ていた。

## 修正（v0.3）

- 第 2 フックは層の時刻を読まない。第 1 フックが作る刻みは構造上ちょうど係数ぶんなので、`z = (+0x25C.z ÷ +0x2B2) × 係数 × 距離係数` にした。
- 追加の安全条件: プレイヤー自身の状態がカテゴリ 1・サブ状態 1（走り）のままであること（タグはこのフックの時点で 1 フレーム古い）、層がループモーション（`+0x23C` bit2）であること、総フレーム `+0x2B2` が 0 でないこと。
- マーカーは `SPR3`。パラメータ配置は v0.2 と同じ。

## 挙動（v0.2 から変更なし）

- 発動: サブ状態 1（走り）でスティックを倒し続けて 45 フレーム（1.5 秒）。以後 15 フレームで 1.0 → 1.4 倍へ。
- 解除: 走り以外の状態、スティックを離す、1 フレームで向きが 60°（設定値）以上変わる急旋回。
- ジャンプ: 走りからの前方ジャンプは空中の前進速度 `+0x108`（元 260／フレーム）にその時点の係数を掛ける（フェーズ 6 で 1 回）。ジャンプ中と着地直後の待機 1 フレームはカウンタ保持。
- 走り中の根の前進量を平均で一定化（フラグ bit2、既定 ON）。左右揺れ x はそのまま。足は最大 ±22% 一時的に滑る。

## 導入

Claude 側で `GameSettings\GPNJ08.ini` の `[OnFrame]` に反映済み（`Sprint Run v0.3` 有効、v0.2 は無効で残置、v0.1 は削除）。camera v0.6・move v0.14・ED terrain v0.1 と同時に使う。本体 `0x8018D800`〜（1000 bytes ＋ データ 52 bytes、パラメータ `0x8018DD80`〜）。フックは 2 本: `0x800AFE78`（プレイヤー更新の状態処理直後）と `0x800A08E8`（モーション更新の root motion 適用直前）。旧セーブステートは旧コードを持ち込むので、ゲームを起動し直してから確認する。

## 検証

- Unicorn 2.1.4 で 679 ケース通過。実 DOL のフレーム進行 `0x800A1770` でハンドラの tick とフックを 400 フレーム交互に実行し、サンプル時刻の刻みが毎 tick 1.3906〜1.4062（目標 1.4）、足音イベント 52 回が 6／15 交互、ループ tick 後のフラグ復元、急旋回解除、スティック解放、ジャンプ継承と保持、他状態リセット、レジスタ不変を確認。
- 追加: 実順（第 2 フック → ゲームの進行 → 第 1 フック）で 214 tick を回し、毎 tick の z が「平均 × その tick の刻み × 距離係数」（±1/64）で 2 倍を超えないこと、定常区間の合計距離がモーション × 係数に一致すること、距離係数 1.25 の追従、bit2 OFF で不変を確認。同じ列で v0.2 の式を計算すると 5 回ワープする（不具合の再現）。
- **Dolphin 実行は未確認。** 実機で見るもの: ワープが消えたか、腰のカクつき（bit2 の ON/OFF で比較）、足音、1.5 秒の発動感、急旋回解除、加速ジャンプ。
