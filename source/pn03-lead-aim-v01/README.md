# P.N.03 偏差射撃 v0.1（Lead Aim）

日本版 **GPNJ08** 用。ロックオン中の通常射撃（掌の弾）が、対象の「今の位置」ではなく「弾が届く頃の位置」を狙うようになる。横に走る Orchidee や突っ込んでくる Birne に、ロックオンしているのに弾が後ろを通る症状への対策。弾速・連射・ダメージ・ヴァネッサの向きは変えない。対象が止まっていれば何も変わらない。

## 仕組み

- 常駐（`0x800AFE84`、回避吸収 v0.2 の連鎖の次）: 毎フレーム、ロックオン対象 `player+0x5B4` の狙点ノード（対象+0x125 のノード番号 → `0x8009EFB0`）の位置を取り、前フレームとの差から速度を平滑化して持つ（係数 0.5）。対象が変わればリセット、1 フレームに 400 以上飛ぶ瞬間（ワープ・出現）は無視。
- 弾速の自動計測: 発射直後（`0x800AF1B0`）に弾のアクターを控え、最初の数フレームの位置差分から 1 フレームあたりの移動量を測って `s_meas` に保存。弾速はエフェクト定義側にあり静的に取りにくいので、実測に寄せた。計測前は既定 4500／フレーム。
- 発射時（`0x800AF16C`、角度計算 `0x800CC574` の呼び出し）: 到達時間 t = |狙点 − 手| ÷ 弾速（上限 90 フレーム）、狙点を速度 × t × lead（1.0）だけ先へずらしてから元の角度計算に渡す。

## パラメータ（`0x8018C500`〜、タグ `LEAD`）

| 項目 | 既定 | 番地 | 行 |
|---|---|---|---|
| flags | 3（bit0 有効、bit1 実測弾速を使う） | `0x8018C504` | `0x8018C504:dword:0x00000003:0x00000000` |
| lead（予測の効き、0〜1） | 1.0 | `0x8018C508` | float |
| max_t（到達時間の上限、フレーム） | 90 | `0x8018C50C` | float |
| s_default（計測前の弾速） | 4500 | `0x8018C510` | float |
| smooth（速度の平滑化係数） | 0.5 | `0x8018C518` | float |

観測用: `s_meas`（実測弾速）`+0x14`、`vel` `+0x34`、`last_t` `+0x70`、`shots_total/led` `+0x68/+0x6C`。

本体 `0x8018C100`〜（948 bytes、250 行）。Unicorn テスト 15 ケース。

## 導入

Claude 側で `GameSettings\GPNJ08.ini` の `[OnFrame]` に反映済み（`Lead Aim v0.1` 有効）。ゲームを起動し直せば反映される。回避吸収 v0.2 と同時使用前提（連鎖の順序: 加速走り → 軌跡色 → 回避吸収 → 偏差射撃）。

## 検証

**ゲーム内未確認。** 確認したいこと: Orchidee／Birne に通常弾が当たるようになったか、止まっている敵・近い敵で違和感がないか、エナジードライブの弾や敵弾に変化がないこと。
