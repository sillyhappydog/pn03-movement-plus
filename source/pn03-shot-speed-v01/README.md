# P.N.03 通常弾の弾速 v0.1（Shot Speed）

日本版 **GPNJ08** 用。ヴァネッサの通常射撃（掌の弾）の速度を **2.5 倍**にする（素は 1,800 ユニット／フレーム＝実測）。エナジードライブの弾（対象を持つ）と敵弾は変えない。連射・ダメージ・射程判定の仕組みはそのまま。

- 弾アクター（クラス 3）は毎フレーム「位置 `+0xC0` ＋ 速度ベクトル `+0x100`」で進む（飛行中ハンドラ `0x8000F690` → 移動と当たり `0x8000B770`）。
- `+0x100` はクラス初期化 `0x80010004`（弾の最初のフレームにエフェクト要素の更新から呼ばれる）でエフェクト要素の `+0x40` からコピーされ、以後は絶対角で回転されるだけ（大きさ不変）。
- フック `0x800100C0`（コピー直後）で、クラス 3・所有者がプレイヤー（root+0x50 の先頭）・対象なし（`+0x12C == 0`）のときだけ `+0x100`〜`+0x108` に係数を掛ける。

## パラメータ（`0x8018C700`、タグ `SPD1`）

| 項目 | 既定 | 番地 |
|---|---|---|
| flags（bit0 有効） | 1 | `0x8018C704` |
| factor（倍率、float） | 2.5 | `0x8018C708` |

観測用: `count`（掛けた弾数）`+0x0C`、`last_v`（最後に掛けた後の速度ベクトル）`+0x10`。再焼きは `py -3.13 work\build_speed_v01.py 2.0` のように倍率を引数で。

本体 `0x8018C600`（144 bytes、40 行）。Unicorn テスト 6 ケース。偏差射撃 v0.1 と併用前提（弾速は偏差側が実測するので係数を変えても追従する）。

## 導入

Claude 側で `GameSettings\GPNJ08.ini` の `[OnFrame]` に反映済み（`Shot Speed v0.1` 有効）。ゲームを起動し直せば反映される。
